# METODOS 

- Construtor
    Inicia o objeto, atribuindo valores iniciais aos atributos do objeto.

- Metodos do tipo GET
    Permitem acessar os valores dos atributos do objeto, sem modificar seu estado.

- Metodos do tipo SET
    Alterar um valor de um atributo do objeto, modificando seu estado. LEMBREM QUE NEM TODO OBJETO PRECISA DE UM SET

# CLASSES

Existem classes chamadadas DTOs que são anêmicas, ou seja, não possuem comportamento, apenas atributos. Elas são usadas para transportar dados entre diferentes camadas de uma aplicação.
